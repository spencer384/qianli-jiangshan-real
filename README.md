# 江山千里 · 實景寫真卷 (3D-Real)

將清代方琮《仿王希孟江山千里卷》（47,242 × 2,072 原始長卷）分段轉譯為真實自然地理空拍攝影，並無縫羽化拼接為 **24,960 × 1,080** 超寬長幅全景，提供與原稿 **1:1 上下同步對照**的線上展廳。

- **線上瀏覽**：https://spencer384.github.io/qianli-jiangshan-real/
- **風的異想實驗室**：https://spencer384.github.io/

## 操作說明
- **滑鼠滾輪**：以游標為中心同步放大／縮小上下兩幅長卷（100%～450%）。
- **Ctrl + 滾輪**：左右同步橫向平移。
- **左鍵拖曳**：2D 上下左右同步平移。
- **全圖導覽進度條**：點擊或拖曳下方縮圖進度條可快速跳轉全卷位置。
- **游標鏡像對照準心**：滑鼠懸停於任一長卷時，另一幅相同座標位置將顯示金色對齊圓點。
- **💬 評論與修改建議**：可鎖定目前位置座標寫入建議、複製 Markdown 清單或直接送出至 GitHub Issues。
