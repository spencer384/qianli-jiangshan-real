# 江山千里 · 實景寫真卷 (3D-Real)

將清代方琮《仿王希孟江山千里卷》（47,242 × 2,072 原始長卷）分段轉譯為真實自然地理空拍攝影，並無縫羽化拼接為 **24,960 × 1,080** 超寬長幅全景，提供與原稿、**3D 虛擬數位山水**三位一體 1:1 長度比例精準對照的線上展廳。

- **線上瀏覽**：https://spencer384.github.io/qianli-jiangshan-real/
- **風的異想實驗室**：https://spencer384.github.io/

## 操作說明
- **📏 3D 與原圖長度 1:1 精確校準**：依據原卷 23.1:1 展幅公式，3D 攝影機視角與景深精密校準為 1:1 對齊，山峰寬度、高低比例與水平捲動速度完全一致；亦可一鍵切換為「🦅 全卷遠眺總覽」。
- **🚩 頂部十景快速選擇列**：點選頂部「選擇場景段落比較」標籤列，3D 虛擬、原稿與實境長卷將同步飛躍對齊該經典景點，並顯示場景解析。
- **🎨 多場景比較組合**：可在「3D水墨＋原稿＋實境」、「3D體素＋原稿＋實境」、「3D水墨＋實境」、「3D水墨＋原稿」等自訂場景模式間任意切換。
- **🌐 3D 虛擬場景雙向聯動**：在 3D 場景內左鍵平移、右鍵旋轉、滾輪縮放；移動 2D 長卷或導覽條時，3D 攝影機同步巡航至對應景點。
- **🔍 2D 滑鼠滾輪縮放**：以游標為中心同步放大／縮小上下長卷（100%～450%），3D 視角景深同步縮放。
- **↔️ Ctrl + 滾輪**：左右同步橫向平移。
- **左鍵拖曳**：2D 上下左右同步平移。
- **全圖導覽進度條**：點擊或拖曳下方縮圖進度條可快速跳轉全卷位置。
- **游標鏡像對照準心**：滑鼠懸停於任一長卷時，另一幅相同座標位置將顯示金色對齊圓點。
- **💬 評論備份與匯入**：可鎖定目前座標位置寫入建議，支援一鍵匯出 JSON 備份或匯入合併留言，升級部署絕不覆蓋。
